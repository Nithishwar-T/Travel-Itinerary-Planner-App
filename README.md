\# Travel Itinerary Planner



A full-stack travel planning application for discovering destinations, planning trips, and creating personalized travel itineraries.



\## Tech Stack



\### Frontend

\- Angular

\- TypeScript

\- SCSS



\### Backend

\- ASP.NET Core Web API

\- C#

\- Entity Framework Core



\### Database

\- Microsoft SQL Server



\### API Testing

\- Postman

\- Swagger / OpenAPI



\### Version Control

\- Git

\- GitHub
